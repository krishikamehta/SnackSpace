# SnackSpace - Cafeteria Ordering Website

SnackSpace is a responsive web application designed for our college cafeteria to streamline the food ordering process. It serves 500+ students daily, reducing wait times and enhancing efficiency.

## Features
- **Online Ordering System**: Students can order food online, reducing queue times.
- **Admin Panel**: Cafeteria staff can manage 100+ dishes, update availability, and track orders.
- **Responsive Design**: Works across multiple devices for easy accessibility.
- **Performance Improvement**: Decreased wait times by 40% and reduced manual effort by 60%.

## Technologies Used
- HTML, CSS, JavaScript
- Node.js
- MongoDB

## Installation & Setup
Follow these steps to set up and run the project locally:

1. Clone the repository:
   ```sh
   git clone <repository-url>
   cd SnackSpace
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the project:
   ```sh
   npm run
   ```
